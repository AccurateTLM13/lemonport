# FreeSource Website

Static launch page for FreeSource License 1.0.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — copy-license interaction
- `LICENSE.txt` — downloadable license text

Open `index.html` directly or serve the directory with any static web server.

## Before launch

1. Replace `[YEAR]` and `[OWNER]` in `LICENSE.txt` if this page itself is being released under FreeSource.
2. Decide whether “Draft release” should remain in the footer.
3. Have the license language reviewed by qualified counsel before claiming universal legal validity.
