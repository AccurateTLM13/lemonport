### Core idea
MORROW EDITIONS publishes carefully produced work about:
-   art
-   photography
-   architecture
-   design
-   place
-   material culture
-   independent creative practice

The website should feel like a serious contemporary publishing house with a strong editorial point of view.

It should feel:

-   intelligent
-   tactile
-   editorial
-   collected
-   contemporary
-   visually confident
-   culturally literate
-   quiet when appropriate
-   dense when useful

It should **not** feel like:

-   a generic bookstore ecommerce template
-   a fashion brand
-   a lifestyle blog
-   a newspaper website
-   a portfolio template
-   a brutalist design exercise
-   a beige minimalist brand
-   a collage
-   a masonry gallery
-   a grid of identical book cards

Do not introduce literal weaving, thread, textile, loom, stitching, fabric, or craft imagery simply because the LOOM skill is being used.

The visual identity should come from the supplied design system itself.
