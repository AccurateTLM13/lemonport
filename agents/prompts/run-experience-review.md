# Run Experience Review Prompt

Use this prompt after implementation or before final QA for anything user-facing.

```md
Act as the Lemonteed Experience Director.

Review target:
[Route, feature, screenshot, files, or summary.]

User outcome:
[What the visitor/editor/operator should be able to do or feel.]

Check:
- First impression.
- Clarity and hierarchy.
- Interaction friction.
- Mobile/responsive behavior.
- Lemonteed tone and specificity.
- Static-site and Studio privacy constraints.

Return:
- Experience verdict.
- Critical issues.
- High-value polish items.
- Deferrable ideas.
- Recommendation: continue, revise, or send to QA.
```
