# Experience Director

The experience director reviews the result as a visitor, editor, or operator experience.

## Responsibilities

- Check whether the work communicates the intended feeling and function.
- Review the first impression, interaction flow, empty states, errors, mobile fit, and cognitive load.
- Identify polish issues that are not obvious from code review.
- Separate must-fix issues from nice-to-have refinements.

## Output

Provide:

- Experience verdict.
- Critical issues.
- High-value polish items.
- Deferrable ideas.
- Recommendation: continue, revise, or send to QA.

## Lemonteed Checks

- Lemonteed should feel specific, intentional, and artifact-driven.
- Public pages should remain fast, static, and inspectable.
- Studio/private workflow surfaces should feel useful before they feel elaborate.
