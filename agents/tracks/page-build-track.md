# Page Build Track

Use this track for a new static page or substantial revision to an existing public page.

## Sequence

1. Orchestrator defines the visitor outcome.
2. Structure Worker maps route, shared chrome, page-owned content, scripts, and source files.
3. Content Worker drafts hierarchy, labels, and metadata.
4. Design Worker defines layout and responsive direction.
5. Implementation Worker builds with plain HTML, CSS, and JavaScript.
6. Experience Director reviews the page as a visitor.
7. QA Worker validates and checks the local route.
8. Orchestrator updates status and handoff.

## Required Checks

- Public page remains static.
- Shared chrome changes are deliberate.
- Generated files are not hand-edited.
- Content/gallery changes use source JSON.
- Mobile behavior is reviewed.

## Example Use

For the Lighthouse Handoff page, use this track to define the route, page goal, content hierarchy, visual treatment, static implementation files, and final QA checklist before public site files are touched.
