08 PRODUCT EXPLANATION / RELAY

What Relay does

Operational software for AI agents

The interface uses manual logic where that logic helps. The product itself can still be explained in ordinary language.

Deployments should leave evidence behind.

Relay is a deployment and operations platform for teams running AI agents in real environments. It brings configuration, evaluations, tool permissions, release procedures, production observation, and revision history into one controlled workflow.

Instead of reducing an agent to a green dot on a dashboard, Relay shows the operating record around it. Teams can see which configuration was evaluated, which permissions were approved, which build was deployed, what changed between revisions, and whether the release was actually verified.

That makes Relay useful after deployment too. When an agent fails, behaves differently, or needs to be changed, operators have a documented starting point rather than reconstructing the release from chat threads, logs, configuration files, and memory.
