Lemon DOM

Juicy UI effects for plain old websites.

A lightweight, dependency-free visual effects library — glass, glow, squeeze, zest, and peel — usable by simply opening index.html in a browser.

Effect gallery

Five data attributes. Drop them on any element, then call LemonDOM.init().

Glass

data-lemon-glass

Frosted surfaces with backdrop blur, soft borders, inner highlights, and translucent gradients.

Juice

data-lemon-juice

Cursor-follow radial glow driven by --lemon-x and --lemon-y.

Squeeze

data-lemon-squeeze

Lemon-shaped pods that bulge wide, compress tall, and spring back when you let go.

Zest

data-lemon-zest

CSS-only grain overlay for a premium, slightly analog finish.

Peel

data-lemon-peel

Scroll-triggered reveal via IntersectionObserver — mask, clip-path, and motion.

Basic usage

Three files. No npm. No bundler. Just link and init.

HTML + JS 
<link rel="stylesheet" href="lemon-dom.css">
<script src="lemon-dom.js" defer></script>

<div
  data-lemon-glass
  data-lemon-juice
  data-lemon-squeeze
  style="--lemon-blur: 24px; --lemon-accent: #ffe66d;"
>
  Custom glass card
</div>

<script>
  LemonDOM.init();
  // or apply individually:
  LemonDOM.glass(".card");
  LemonDOM.juice(document.querySelector(".hero"));
</script>

Notes

Inspired by Liquid DOM

Lemon DOM is a practical, no-build-step tribute inspired by Liquid DOM by Andrew Prifer. It is not affiliated with Liquid DOM, does not claim feature parity, and does not copy its source code.

Browser support & fallbacks

Glass uses backdrop-filter where supported and falls back to a solid translucent surface elsewhere. Peel and squeeze honor prefers-reduced-motion. Juice requires pointer events; touch users still get the static glass look.
